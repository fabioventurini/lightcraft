# LightCraft app icon

A **two-letter monogram on a near-black tile**, in the Adobe Creative Cloud layout: the suite reads
as one family at a glance, and each app is told apart by its hue and its letters alone.

## Palette

Exactly two colours, both derived from the app's existing brand hue `#f2a516`.

| Colour | Hex | Used for |
|---|---|---|
| Tile | `#2A1B00` | the full-bleed rounded field |
| Monogram | `#FFB429` | the letters `Lc` |

The tile is solved for a constant *perceived* brightness across the whole suite (relative
luminance 0.013), not a constant HSL lightness — otherwise the amber and green apps read far
lighter than the blue ones. The monogram keeps a fixed HSL lightness (0.58) so each hue stays
vivid.

## Geometry

A 512-unit tile (`viewBox="0 0 512 512"`), rounded square with `rx=112`, no border. The macOS
renders pad it onto Apple's 824/1024 icon grid; the Windows and Linux renders crop 22 units off
each side so the mark reads at 16-48 px.

## Regenerating

Generated by `_icon-tools/make-adobe-style-icons.sh` in the craftapps working tree (ImageMagick +
iconutil; it does not need resvg or cargo, unlike `packaging/icons.sh`).

**Known limitation:** the master SVG sets the monogram as live `<text>` in Helvetica Neue, so a
renderer without that font substitutes another. Converting the glyphs to paths would make it
self-contained.
